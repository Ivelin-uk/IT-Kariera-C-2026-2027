# Пример с exceptions в C#

Стартиране от основната папка на проекта:

```sh
dotnet run --project Demo_09
```

Програмата прочита две цели числа и извършва целочислено деление.
Например `10 / 3` дава `3`.

- `try` съдържа операциите, които могат да хвърлят изключение.
- `catch` обработва съответния тип изключение. При изключение останалите
  инструкции в `try` се пропускат и се изпълнява подходящият `catch`.
- `finally` се изпълнява и при успех, и при обработено изключение. Тук само
  извежда съобщение; обичайно се използва за освобождаване на ресурси.

Въведете всяка стойност на отделен ред:

| Вход | Резултат |
| --- | --- |
| `10`, `2` | Успешно изчисление: `5` |
| `10`, `0` | `DivideByZeroException` — деление на нула |
| `abc` | `FormatException` — невалиден формат |
| празен ред | `FormatException` — липсва число |
| `2147483648` | `OverflowException` — стойността е по-голяма от `int.MaxValue` |
| `-2147483648`, `-1` | `OverflowException` — резултатът не се побира в `int` |

Във всички тези случаи накрая се извежда „Край на опита за изчисление.“.
