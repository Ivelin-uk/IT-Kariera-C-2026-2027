# Собствено изключение: банкова сметка

Стартиране от основната папка на проекта:

```sh
dotnet run --project Demo_10
```

Примерът изпълнява пет последователни опита за теглене от една сметка.
Началната наличност е `100`. Сумите са зададени в `Program.cs`.

| Сума за теглене | Резултат | Наличност след опита |
| --- | --- | --- |
| `50` | Успешно теглене | `50` |
| `80` | `InsufficientFundsException` | `50` |
| `0` | `ArgumentOutOfRangeException` | `50` |
| `-20` | `ArgumentOutOfRangeException` | `50` |
| `50` | Успешно теглене на цялата наличност | `0` |

`InsufficientFundsException` е собствен клас, който наследява `Exception`.
Съдържа съобщение, поисканата сума и наличността при възникване на грешката.

В `BankAccount.Withdraw` инструкцията `throw` прекратява метода при невалидна
операция. Наличността се променя само след успешни проверки.

В `Program.cs` подходящият `catch` обработва изключението. След това цикълът
продължава със следващата сума. `finally` показва наличността след всеки опит,
независимо дали тегленето е успешно или грешката е обработена.

Сумите са от тип `decimal`, а суфиксът `m` указва литерал от този тип.
